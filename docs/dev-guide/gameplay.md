# 玩法

整个游戏的成长曲线就是教学曲线：玩家从「信军师的数字」走到「自己拿数字、心里有数」。本文是全局结构，页面落地见 [页面](./pages.md)。

## 游戏流程

```text
开场页 ──→ 第1周 ──→ 第2周 ──→ 第3周 ──→ 第4周 ──→ 结局页 ──→ 复盘
”我要摆摊“   信任崩塌     掌控感      危机      决算    点破一句   带着数据再来
```

只有四种页面：开场、主场景、周结算、结局，复盘可跳过。游戏时长不变，28 天约 30 分钟；从「每天打开同一个页面点按钮」变成「一个月里剧情在往前走」。

关键手法是脚本节点加系统方差的组合拳：随机性让游戏活着，但每个教学节拍用脚本钉死在具体某天，保证无论运气如何，课程一定发生。

## 四幕结构

### 第1周 信任崩塌：数字是猜的

- 第1天：军师信心满满给出「日均 150 没问题」的预测，玩家被迫先出摊（教学即强制选择）；当天实测因大方差暴跌，「军师错了」这一锤必须发生在第1天。
- 第3天：军师主动认错：「这几个数我是编的。你去隔壁摊数一晚，我才能算准。」第一个缺口任务由此推出，玩家不是为了教程去做，是为了救局去做。
- 第7天：第一次周结算，看到预测与实际的巨大误差，误差条红得刺眼。

### 第2周 掌控感：数据是力量

- 探店、盲测陆续完成，方差肉眼可见地收窄，不靠面板数字告诉玩家变强，让他从摊位前排队的人里看见。
- 解锁机制跟上：探店数据解锁「调整定价」，盲测数据解锁「换底料」——数据不只是让预测变准，它解锁本来没有的选择，这是「AI 给流程、人供数据」的可玩版本：军师能列出选项，但选项要数据喂熟了才能用。

### 第3周 危机：数据会过期，竞争会来

- 第15天脚本钉死：对手摊位出现，压价事件链启动，跟降导致老客流失、三天连降，机制自己说话。
- 第1周探的店，数据开始标灰过期，玩家第一次面对「重新探还是赌一把」，维护成本进入游戏。
- 这一周没有新知识，只有旧课在压力下的综合运用。

### 第4周 决算

- 最后 7 天没有新事件，方差、库存、老客、竞争全部叠加，玩家用一个月攒下的数据资产打完这局，周末结算即结局。

## 周循环

天的循环是操作（选一张行动卡），周的循环才是游戏的呼吸：

1. 周一：军师预测本周，如「我这版模型预测日均 110，但我缺翻台率，误差 ±40」；
2. 周二至周六：玩家分配行动（出摊、探店、盲测），摊位场景给即时反馈；
3. 周日：周结算，预测对比实际，误差条可视化；
4. 军师归因：「误差主要出在天气假设——你要是能搞到翻台率，我下周能压到 ±15」；
5. 缺口清单更新，成为新一周的决策依据。

预测误差条就是玩家的经验条，等级、技能树全都不需要：玩家看着预测从 ±40% 缩到 ±10%，成就感来自同一套系统，而这套系统恰恰就是课程本身。

## 军师的弧线

军师不能四周一个腔调，他的变化替课程做情绪表达：

- 第1周：自信的顾问，「模型说没问题」，当场被打脸；
- 第2周：谦逊的合作者，「你去拿数，我来算」，数据到位后逐渐准了、开始有底气；
- 第3周：坦诚的局限，「明天会不会下雨我不确定，这部分你比我强」，玩家学会分辨哪些信 AI、哪些必须自己来；
- 结局：一句话总结他和玩家的关系。

这样「AI 的作用与边界」这一课不靠说明书，是玩家跟一个角色相处一个月处出来的。

## 结局

胜负乘数据完整度，是 2×2 矩阵：

| | 数据齐（缺口 ≥ 5 回填） | 数据缺（靠猜） |
|:--|:--|:--|
| 达标 | 「你心里有数」——赢在亲手拿的数字，这一课闭环 | 「运气替你付了学费」——明确告诉玩家这局是蒙的，赌场没有常胜将军 |
| 不达标 |「数字对了，执行输了」——课程已学会，输在别的账 | 「你全程在赌」——最疼也最有教育意义 |

四个结局共用一句点破格式，只在结局页说这一次。特别防住一个漏洞：靠运气蒙混过关的玩家绝不能拿到「你学会了」的结局，否则课程被随机性瓦解。

破产线（现金触底立刻终局）开局就摆在明面并保留，它让「拍脑袋」不止输得难看，还可能中途暴毙。

## 复盘

游戏结束，课程开始。复盘页展示这 28 天预测误差从多少缩到多少、哪几个数字是亲手拿的、关键转折是哪天，配「再来一局」与「看看真实世界」两个按钮：游戏里蹲两个晚上就能回填缺口，现实里滁州的夜市也是。这是游戏和「验证滁州串串」初衷握手的地方。
