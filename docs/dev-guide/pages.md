# 页面

五个页面，同一套设计语言。全局结构见 [玩法](./gameplay.md)，实施顺序见 [ROADMAP](../../ROADMAP.md)。

设计缘起：现三栏全是卡片、表格、清单与公式，是一块经营分析看板——玩家经营的是串串摊，屏幕上却看不到摊位。页面重构的原则是场景驱动：反馈、情绪、后果都发生在一个能「看见」的地方。

## 通用规矩

- 一套设计语言管五页：深色夜市底加暖黄灯光色（锅的热气、灯串），圆角卡片，不做五页五种风格；
- 每页只有一个主动作，屏幕上最大的东西永远是玩家此刻该点的；
- 数字能用场景表达的就不用数字：库存用签子堆高度、生意用客人数量、竞争用对手摊剪影，纯数字只允许出现在账本抽屉里；
- 信息不超过两屏深度：第一屏永远可玩，账本、缺口、公式藏在第二层抽屉里。

## 开场页

一屏，一个目的：三十秒内让人知道自己在干嘛。

```text
┌─────────────────────────────────────┐
│                                     │
│        [串串摊简笔画/剪影]            │
│                                     │
│         滁州夜市·串串摊               │
│                                     │
│   你揣着2万块，想在夜市摆个串串摊。    │
│   28天，日均150签，做到就站稳了。      │
│   一个AI军师说要帮你。                │
│                                     │
│        [ 出摊 ]   ← 唯一按钮          │
│                                     │
└─────────────────────────────────────┘
```

三行文案，一个按钮，没有别的。手机竖屏优先，夜市题材天然适合拿着手机玩。

## 主场景页

游戏的心脏，90% 的时间在这。竖屏从上到下分五段：

```text
┌─────────────────────┐
│ 第8天·第2周   ¥13,200 │ ← 顶栏：只有天数和现金两个数
│ 日均 102/150 ▓▓▓░░░  │    日均进度条（红=危险 黄=紧张 绿=安全）
├─────────────────────┤
│                     │
│    【 场 景 区 】     │ ← 占屏幕一半，全页视觉重心
│   🌧 夜市·小雨        │
│   🍲 冒热气的锅        │
│   🍢 签子堆(高度=库存) │
│   🚶客人×5(排队=生意)  │
│                     │
│  军师(气泡):”下雨了,   │
│  但周五夜市老客会来,   │
│  我赌今晚120——不过    │
│  隔壁翻台率我是猜的“   │
├─────────────────────┤
│  今天做什么？          │
│ ┌─────┬─────┬─────┐ │
│ │出摊  │探店  │盲测  │ │ ← 三张行动卡，一屏放下
│ │赚钱  │¥150  │¥80  │ │    卡面写机会成本
│ │但按猜 │把猜变 │找到  │ │
│ │的数字 │实测   │冠军料│ │
│ └─────┴─────┴─────┘ │
├─────────────────────┤
│ 账本    缺口(2)       │ ← 底部两个抽屉按钮，默认收起
└─────────────────────┘
```

逐区的设计决定：

- 顶栏只留天数、现金与日均进度条；风险底线降级为临近时才弹的警告，信息完整度改成军师嘴里的一句话（「我还缺三个数」）。
- 场景区占掉一半屏幕，这是「管理后台」和「游戏」的分界线。出摊后的反馈全在这里发生：客人小人走过来坐下、下雨走两个、第 15 天出现对手摊剪影。玩家不读日志，他看摊。
- 军师从面板改成两行气泡，嵌在场景下方而非侧栏；删掉方案卡、能力分、输入依赖与证据等级，术语全部消化在口语里——「我赌今晚 120」是预测，「翻台率我是猜的」是缺口。关键节拍（第 1 天被打脸、第 3 天认错）气泡变高、有动画。
- 三张行动卡按下即过天：卡面第一行是动作，第二行是代价，让玩家选之前直面「今天赚钱」和「把猜变实」的交换。不要确认弹窗、不要中间页，一天一次点击，30 分钟玩完 28 天的节奏全靠这里。
- 缺口从清单页变成底部角标，「缺口(2)」点开是抽屉：「隔壁摊翻台率：军师在猜｜影响：预测 ±40%」。清单消失了，入口还在，想深究的人自己点。
- 账目、公式、纪律收进底部抽屉，常驻纪律面板整个删除——跟降的代价由事件链机制承担，不需要一块常驻文字反复提醒。
- 当天结算不用弹窗，用场景加飘字：客人散去、签子堆变矮、「+137 签」从摊位飘出。弹窗打断节奏，飘字不打断，周日才用结算页。

## 周结算页

每周日一次，一屏：

```text
┌─────────────────────┐
│      第2周·结算       │
│                     │
│  军师周一预测: 110签/天 │
│  实际:      118签/天  │
│  误差:     ±7%  ▓░░  │ ← 误差条，横向对比第1周
│  (第1周是±42%)        │    收窄=成长，一眼可见
│                     │
│  ”翻了台率你帮我拿到   │
│   后,我算得准多了“    │
│                     │
│  缺口: 还差1个(底料成本)│
│                     │
│      [ 进入第3周 ]    │
└─────────────────────┘
```

这页只有一个使命：让玩家看见误差条在一周周缩短，别的都是配角。

## 结局页

第 28 天晚上，一屏：

```text
┌─────────────────────┐
│                     │
│      🏆 你心里有数     │ ← 结局标题（四选一）
│                     │
│   日均 156签 · 盈余 ¥8,400│
│   6个数字，5个是你亲手拿的│
│                     │
│  ”军师的模型,你的数字——│
│    这摊子,是你的了“    │
│                     │
│  [看复盘]  [再来一局]  │
└─────────────────────┘
```

大标题加两行数据加一句点破加两个按钮，点破只在这里说这一次。结局的四种标题与点破规则见 [玩法](./gameplay.md)。

## 复盘页

可跳过，但值得看：

```text
┌─────────────────────┐
│      这28天           │
│                     │
│  预测误差: 42%→7%     │ ← 一条下降曲线，课程的可视化
│   ███▆▅▃▂           │
│                     │
│  ✅ 第3天 你去探了店    │ ← 关键转折时间线
│  ✅ 第9天 你盲测出冠军料│
│  ⚠️ 第16天 你跟了降价   │
│     ——三天老客流失     │
│                     │
│  💡 游戏里蹲两晚能回填  │
│  缺口——滁州的夜市也是   │
│                     │
│   [再来一局]          │
└─────────────────────┘
```

一条误差曲线、一条大事记、一句通向现实的话，这是「验证滁州串串」初衷落地的地方。
